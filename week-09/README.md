# Week 09 
# CSV File Handling & Data Analysis

This project demonstrates how to store and analyze structured data using CSV files in python.

The program allows users to store student names and scores in a CSV file and the analyze the data to calculate the class average and identify the top-performing student.


## Project Overview

The script performs two main tasks:

1. Stores student records (name and score) in a CSV file.
2. Reads the stored data to calculate:
    - The class average score
    - The top performer with highest score

This project demonstrates practical file handling and simple data analysis using Python.


## Features

- Add student names and scores
- Save records to a CSV file
- Read stored data from the CSV file
- Calculate the class avarage
- Identify the highest scoring student
- Handle invalid input and missing files

## Concepts Applied

- File handling in Python
- Reading and writing CSV file
- Data processing with loops
- Error handling with try/except
- Basic statistical calculations

## How to Run

Run the program using Python:

Navigate to the `week-09` directory then run:

python student_scores_manager.py
 
## Learning Objective

The goal of this project is to understand how structured data can be stored, processed, and analyzed using CSV files in Python.
