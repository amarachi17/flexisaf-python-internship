# Week 10
# Python Modules (Custom Calculator)

This project demonstrates how to create and use a custom Python module.

## Overview

A simple calculator program that performs:
- Addition
- Subtraction
- Multiplication
- Division

The math operations are defined in a separate module (`math_tools.py`) and imported into the main program (`calculator_app.py`).

## Structure

week-10/
- math_tools.py
- calculator_app.py
- README.md

## How to Run


Run the program using Python:

Navigate to the `week-10` directory then run:

python calculator.py

## Concepts

- Python modules
- Importing custom files
- Code reusability
- Function based design
