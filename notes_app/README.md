# Flask Notes App

A simple Notes Application that allows users to:

- Add notes
- Edit notes
- Delete notes

Built using:

- Python
- Flask
- Tailwind CSS
- CSS

## How to Run

```bash
git clone https://github.com/amarachi17/flexisaf-python-internship/tree/main/notes_app
