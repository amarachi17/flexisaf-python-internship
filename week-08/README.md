Python Error Handling & Debugging

This week focuses on building resilient Python scripts that handle errors gracefully when interacting with external systems and files.

Two mini projects were implemented to demonstrate pratical debugging, exception handling, and safe program execution.

## Project 1: API Request Script

This script makes a request to a public API and retrieves data while handling possible errors that may occur when communicating with external services.

### Features

- Sends a request to a public API
- Handles network connection errors
- Handles request timeouts
- Detects invalid API responses
- Displays clear and helpful error messages to the user

### Skills Demonstrated

- Working with external APIs
- Using the `requests` library
- Exception handling with `try/except`
- Debugging unpredictable program behaviour


--------


## Project 2: File Backup Tool

This script copies the contents of one file into another, functioning as a simple backup tool.

### Features

- Prompts user for source file
- Prompts user for destination file
- Prevents accidental overwriting
- Handles missing files
- Handles file access permission errors

### Skills Demonstrated

- Python file handling
- Input validation
- Error handling
- Safe file operations



--------


## How to Run

Run each script using Python:

Navigate to the `week-08` directory then run:

python api_request_tool.py
or
