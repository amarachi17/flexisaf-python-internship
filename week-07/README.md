# CLI To-Do List App (Function-Based)

A modular command-line To-Do List application built with Python.

This project demostrates structured programming using functions, file seperation, loops, and input validation.

## Project Structure

todo_cli_app/
- main.py  # Handles menu and user interaction
- task_manager.py  # Contains all task related functions

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Clear menu navigation
- Handles invalid input politely
- Runs continuously until userr exits

## Technical Concepts Applied

- Custom function definitions
- Importing functions between files
- Modular code organization
- Lists and dictionaries
- Loops ('for', 'while')
- Built-in functions ('len()', 'enumerate()')
- Exception handling ('try/except')

## How to Run
Navigate to the `week-07` directory then navigate to `todo_cli_app` and run:
python main.py
