# StudentHub CLI - Task $ Expense Manager

StudentHub CLI is a python console application designed to help students manage academic tasks and track school-related expenses efficiently.

This project demonstrates practical use of Python lists, tuples, list comprehensions, and structures program flow.


----

## Features

### To-Do List Manager
- Add assignments
- View all assignments
- Mark assignments as completed
- Remove assignments
- Tasks stored using Python lists and dictionaries'

### Expense Tracker
- Add school-related expenses (Lunch, Transport, Books, etc.)
- Store expenses in a list of tuples `(category, amount)`
- Filter expenses by category
- Display expenses above a chosen amount
- Uses list comprehensions for filtering

----
